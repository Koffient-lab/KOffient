## Качество

Быстрый набор на видеокарте (методика — [METHODOLOGY.md](METHODOLOGY.md)), рядом исходная модель bf16.
Последний столбец — попарное сравнение ответов на одних и тех же примерах: сколько стало хуже / лучше.

| Задача | `q4_k_m` [95% интервал] | bf16 | хуже / лучше |
|---|---|---|---|
| Вызов функций, англ. (240) | 0,883 [0,837–0,918] | 0,896 | 6 / 3 |
| Вызов функций, рус. (240) | 0,429 [0,368–0,492] | 0,475 | 18 / 7 (p = 0,04) |
| Без лишнего вызова, англ. / рус. (60) | 0,717 / 0,633 | 0,783 / 0,717 | |
| JSON по схеме (200) | 0,895 [0,845–0,930] | 0,895 | 4 / 4 |
| Инструкции, англ. (300) | 0,717 [0,663–0,765] | 0,733 | 32 / 27 |
| Инструкции, рус. (300) | 0,313 [0,264–0,368] | 0,307 | 25 / 27 |
| Суммаризация ROUGE-L, англ. / рус. (200) | 0,304 / 0,206 | 0,307 / 0,203 | |
| Математика, англ. (250) | 0,744 [0,686–0,794] | 0,760 | 22 / 18 |
| Математика, рус. (250) | 0,416 [0,357–0,478] | 0,484 | 37 / 20 (p = 0,03) |
| Знания MMLU, англ. / рус. (285) | 0,505 / 0,372 | 0,540 / 0,375 | 21 / 11, 23 / 22 |

Сжатие почти без потерь: значимо (без поправки на девять сравнений) просели только русский вызов функций и
русская математика. В инструкциях на английском обрывов по лимиту длины 19 из 300.

**Лишние вызовы.** Где функцию вызывать не нужно, модель вызывает её в 28% случаев по-английски и в 37%
по-русски (уже у исходной bf16 — 22% и 28%). Приложение должно проверять вызов перед выполнением.

Близость к bf16: KL 0,105 (англ.) / 0,139 (рус.), самый вероятный токен совпадает в 85% / 85%.

## Скорость и память

Эмулятор Android x86_64, 4 потока, загрузка без отображения файла, контекст 2048, 3 круга, медиана
(не телефонные цифры):

| | |
|---|---|
| Генерация | 36 ток/с (по кругам 33–41) |
| Обработка промпта, 1024 токена | 181 ток/с |
| Первый токен, вопрос 272 токена | 1,4 с |
| Первый токен, запрос с шестью функциями, 1252 токена | 7,2 с |
| Пик памяти | 1,26–1,28 ГБ |

Кэш внимания — 80 КБ на токен (fp16): при контексте 4096, который рекомендует манифест, памяти нужно
примерно на 0,16 ГБ больше (расчёт).

## Как запускать

Общие требования к движку — [sdk-runtime-requirements.md](sdk-runtime-requirements.md). Особенности модели:

- **Не запускать в fp16 и не переквантовывать в Q4_1.** В fp16 модель выдаёт NaN (вероятная причина —
  активации выходят за предел fp16, но это не доказано), а с Q4_1 (его `llama-quantize` сам выбирает для
  части слоёв при квантовании с калибровкой) — бессмыслицу. Q5_1 не проверяли. bf16 и поставляемый K-квант
  работают.
- **Вызов функций** — модель отвечает `<tool_call>{"name": ..., "arguments": {...}}</tool_call>` (по её
  шаблону чата). Вызов проверять перед выполнением (см. выше).
- **Кэшировать системный промпт и описание функций**: без кэша обработка ~1250 токенов описания функций
  занимает секунды даже в эмуляторе.
- **Русский язык** IBM официально не заявляет; цифры выше — наши замеры. По-русски модель заметно слабее,
  чем по-английски, на всех задачах.

## Что не проверено

- Работа на настоящем телефоне (скорость, память, стабильность ARM-сборки).
- Качество свободного диалога (оценка судьёй-моделью).
